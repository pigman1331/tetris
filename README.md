# 俄羅斯方塊

掌機液晶風格的經典俄羅斯方塊，單一 HTML 檔，不需安裝。

- 即時合成的 8-bit〈Korobeiniki〉背景音樂，升級會加速
- 下一個預覽、HOLD、落點提示、最高分記錄
- 鍵盤、手機觸控、藍牙搖桿（Gamepad API）
- 手機振動回饋（落底、消除、按鍵）與搖桿震動，可開關
- 一次消 4 行時，背景輪流浮現照片
- 消除時的寫實爆炸特效（火球、衝擊波、火星、碎片、煙霧與爆炸音），可開關

## 操作
| 鍵盤 | 搖桿 | 動作 |
|---|---|---|
| ← → | 十字鍵／左類比 | 移動 |
| ↓ | ↓ | 加速下落 |
| Space | ↑ / LT / RT | 直接落下 |
| ↑ / X | A | 順時針旋轉 |
| Z | B / X | 逆時針旋轉 |
| C / Shift | Y / LB / RB | 保留 |
| Enter / P | START | 開始・暫停 |
| M | SELECT | 音樂開關 |
